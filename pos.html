Otmane POS

Application de caisse

Otmane POS est une application de caisse développée pour gérer les produits, le panier, les ventes et les paiements.

C# • .NET • SQL • Stripe

Fonctionnalités principales

  • Gestion des produits
  • Gestion du panier
  • Historique des ventes
  • Gestion des clients
  • Paiement par Stripe
  • Paiement par TPE
  • Paiement comptant
  • Calcul automatique TPS et TVQ
  • Impression des tickets
  • Lecture des codes-barres

Technologies utilisées

C# .NET Windows Forms SQL Stripe API

Ce que j'ai réalisé

J'ai conçu et développé cette application de caisse en C# avec Windows Forms.

J'ai intégré une base de données SQL pour gérer les produits, les ventes et les informations de l'application.

J'ai également travaillé sur l'intégration des paiements, l'impression des reçus et la lecture des codes-barres.
